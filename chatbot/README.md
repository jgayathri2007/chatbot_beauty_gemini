Glowora AI Beauty Chatbot

This project is a Flask + Gemini API beauty assistant.

The application is intentionally limited to beauty and personal-care topics:
skincare, skin types, product categories, ingredients, sunscreen, routines,
hair-care, lip-care, nail-care and body-care.

The SQLite product database is created automatically at runtime.

Files:
- app.py
- chatbot_config.py
- requirements.txt
- .env
- .gitignore
- templates/index.html

The Gemini model is configured as gemini-3.1-flash-lite.
